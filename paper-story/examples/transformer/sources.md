# Transformer 示例的依据与简化

原文：Vaswani et al., Attention Is All You Need (2017).
https://arxiv.org/html/1706.03762v7

- 背景和主张：摘要、§1–2。注意力已有先例，贡献是以注意力为核心的完整序列转换架构。
- 结构与前向：§3 / Fig.1；编码器和解码器各六层，保留原始 Post-LN、残差、前馈、因果掩码和交叉注意力。
- 实验：§6.1 / Table 2，WMT2014英语→德语。Transformer big为28.4 BLEU、估算训练FLOPs 2.3e19；此前最佳所报 ConvS2S Ensemble为26.36 BLEU、7.7e19 FLOPs。仅在该明确对比下展示质量更高、估算训练计算量更低。
- 局限：§4 / Table 1，原始全注意力O(n²d)；图示4×4、8×8、16×16分数矩阵，最后的问题是讲解延伸。

中文按“我/爱/你”拆分、二维向量、三头图示、预测概率均为教学简化，不是预训练模型实测。原文基础模型采用8头。toy_attention.py仅用NumPy计算一组合法的缩放点积注意力及加权输出，不运行完整Transformer。

本例是已编写好的讲解和动画工程，不是自动读取任意PDF的通用模型。其他论文由Agent按SKILL.md阅读、组织内容并编写相应分镜与动画。

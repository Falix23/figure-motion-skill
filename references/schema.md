# 数据格式

- `title`: 非空字符串。
- `nodes`: 1–100 个 `{id,label,x,y}`。id 唯一非空，标签为字符串，x 范围 0–940，y 范围 0–560；坐标在 1100×650 画布中表示 160×64 节点的左上角。
- `edges`: 最多 200 个 `{id,from,to}`，id 唯一，端点必须存在且不同。两个以上节点之间可构成有向环。
- `steps`: 1–100 个 `{caption,duration,nodes,edges}`。duration 单位秒，0.2–60；总时长最多 1800 秒；nodes/edges 为当步高亮 id 数组。

每步从累计时间开始，到下一步开始前结束；恰好位于边界时进入下一步。最后一个时间点显示最后一步。节点不会被删除或移位来表示动画，动画只改变高亮与字幕。所有说明属于用户／Agent 提供内容，不由构建器自动推导。

编辑器中的高亮节点与连线字段使用 JSON 数组，例如 `["input,raw", "output"]`，不是逗号分隔文本；id 内可以保留逗号等普通字符。播放经过步骤边界时，编辑器和选中步骤同步到当前步骤；暂停后修改会保存到当前步骤。
